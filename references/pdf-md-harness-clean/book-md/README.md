# 변환 결과

현재 폴더에는 세 권의 PDF를 챕터·소챕터별로 나눈 Markdown이 들어 있습니다.

- `algorithms-nine/`: 챕터 단위
- `computer-science-human/`: 챕터와 목차 기반 소챕터
- `mathematical-statistics/`: 장·부록과 번호형 소챕터

각 책 폴더의 `README.md`에서 파일 목록과 원본 페이지 범위를 확인할 수 있습니다. `detection-report.*`와 `subsection-report.*`는 자동 감지된 경계를 검토하기 위한 리포트입니다.

본문에는 `<!-- page N -->` 형식의 원본 PDF 페이지 표시가 남아 있어, OCR 결과를 원본 이미지와 대조할 수 있습니다.

수식·표·그림·챕터 첫 페이지는 일반 본문보다 OCR 오류 가능성이 높으므로 원본 PDF와 함께 확인하세요.
