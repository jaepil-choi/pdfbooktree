## 결정 내용

- 표준 MIT 본문을 `LICENSE`에 추가하고 PEP 639 metadata에 `license = "MIT"`와
  `license-files = ["LICENSE"]`를 선언했다. license expression만 기록하고 실제
  license file을 wheel에서 누락하는 상태를 허용하지 않는다.
- `pyproject.toml`에 GitHub homepage/repository/issues/documentation URL,
  keywords와 alpha 상태 classifiers를 추가했다. 아직 검증하지 않은 Linux 지원
  classifier는 넣지 않았다.
- 최상위 `pdfbooktree --version`은 source 상수를 복제하지 않고 설치된
  `importlib.metadata` version을 읽는다. metadata가 없는 비정상 실행은
  `0+unknown`으로 명시한다.
- `scripts/smoke-test-wheel.ps1`은 project `.venv`를 재사용하지 않고 별도 Python
  3.12 virtual environment에 새 wheel과 dependencies를 설치한다.
- repo-local `use-pdfbooktree` skill과 package bundle의 CLI reference 및
  `agents/openai.yaml`을 같은 내용으로 갱신했다.
- release Ruff scope는 production/public surface와 유지 대상 도구를 포함하되
  역사적 PoC `experiments/`와 외부 비교 자료 `references/`는 제외한다. 변경한
  실험 파일은 명시 경로로 별도 검사한다.

## 작동 방식

- Typer root callback의 eager `--version` option이 설치 metadata를 출력하고 다른
  command dispatch 전에 exit 0으로 종료한다. `no_args_is_help=true`를 명시해
  기존 인자 없는 help 동작을 보존한다.
- smoke script는 `uv build --no-index`로 sdist/wheel을 만든 뒤 clean venv에
  wheel을 설치한다. 설치 metadata의 `License-Expression=MIT`와
  `License-File=LICENSE`, CLI help/version/config, 실제 PDF inspect/process,
  Markdown manifest와 package skill 파일 5개를 차례로 검증한다.
- 실제 PDF process는 source checkout의 import path가 아니라 clean venv의
  `pdfbooktree.exe`를 호출한다. 실패한 native command나 JSON result는 즉시
  PowerShell exception으로 승격한다.
- 장시간 OCR overlay가 project `.venv`의 실행 파일을 사용 중이므로 저장소
  테스트는 `uv run --no-sync`만 사용한다. clean-wheel smoke는 별도 venv라 이
  프로세스와 충돌하지 않는다.

## 대안과 제외한 선택지

- CLI version을 `cli.py`에 `0.1.0`으로 중복 선언하는 방식은
  `pyproject.toml`과 drift할 수 있어 제외하고 설치 metadata를 canonical
  source로 사용했다.
- license expression만 선언하는 방식은 최초 smoke에서 wheel에 license file이
  포함되지 않는 것을 확인해 제외했다. `license-files`를 별도로 선언하고 smoke
  invariant로 고정했다.
- project `.venv`에서만 CLI를 확인하는 방식은 source checkout 우연과 dependency
  상태를 숨기므로 제외했다. clean venv에 wheel을 설치하고 실제 PDF를 처리한다.
- 전체 Ruff를 통과시키기 위해 역사적 실험과 외부 reference 91개를 일괄
  재format하는 방식은 의미 없는 대규모 diff를 만들므로 제외했다.
