## 변경 배경

- TOC detector model train은 sample manual label registry를 직접 먹는 방식이 아니라, bookmark-guided deterministic TOC detection으로 만든 pseudo label dataset을 기반으로 진행해야 한다.
- 기존 `toc.training`은 `manual_reviewed` label JSON을 입력으로 받아 PDF에서 feature를 재추출하고 soft-label regressor를 학습하는 흐름이라, 300STUDY 같은 대량 pseudo label training 계획과 맞지 않았다.
- sample manual answer는 feature 연구, pseudo label audit, showcase 평가에는 필요하지만 production trainer public interface가 되어서는 안 된다.

## 결정 내용

- `pdfbooktree.toc.training`, `train-toc-detector` CLI, `TocDetectorTrainer` / `TocDetectorModel` public export를 제거했다.
- `train-toc-page-dataset`과 `pdfbooktree.toc.dataset_training`은 유지해 bookmark-guided pseudo label dataset 기반 학습 경로를 남겼다.
- `TOC_PAGE_DATASET_FEATURE_NAMES`에서 runtime without bookmark에서 계산할 수 없는 `bookmark_count`, `detection_confidence`를 제거했다.
- `experiments/labels/answer_toc_ranges_manual.json`을 추가해 현재 sample 5권의 사용자 제공 TOC answer를 sample 검증용 registry로 보관했다.
- PRD와 기존 dataset training 구현 노트 문구를 pseudo label dataset 중심 흐름에 맞춰 정리했다.

## 작동 방식

- bookmark가 있는 대량 PDF는 `detect-bookmark-toc` 경로에서 deterministic bookmark-guided TOC detection을 거쳐 page-level pseudo label dataset row가 된다.
- model 학습은 `train-toc-page-dataset`이 이 dataset row를 입력으로 받아 PDF group 기준 train/test split을 수행한다.
- 학습 feature는 page text/layout feature, previous-page feature, `total_pages`처럼 runtime에서도 bookmark 없이 계산 가능한 값만 사용한다.
- `bookmark_count`와 `detection_confidence`는 dataset provenance나 filtering metadata로는 남을 수 있지만 model input feature에는 포함하지 않는다.
- manual answer registry는 1-based PDF page 기준이며, model train corpus가 아니라 sample 검증과 pseudo label 품질 audit용이다.

## 대안과 제외한 선택지

- manual label trainer를 그대로 두고 사용하지 않는 방식은 제외했다. public API와 CLI에 남아 있으면 실제 train flow가 manual label 기반으로 오해될 수 있다.
- `TocDetectorModel`만 남기는 방식도 제외했다. 기존 loader는 manual soft-label regressor artifact 계약에 묶여 있으므로, pseudo label dataset classifier artifact용 runtime loader는 별도로 설계하는 편이 낫다.
- pseudo label dataset trainer를 제거하지 않았다. 이 경로가 bookmark-guided pseudo labeling 이후 model train을 담당하는 실제 학습 축이다.

## 남은 리스크

- `train-toc-page-dataset`으로 저장한 classifier artifact를 runtime `Processor`에서 로드해 사용하는 경로는 아직 없다.
- `bookmark_count`와 `detection_confidence`를 feature에서 제거했으므로 기존 300STUDY 학습 결과와 지표가 달라질 수 있다. 새 feature set으로 재학습하고 실험 기록을 갱신해야 한다.
- pseudo label 품질은 bookmark-guided deterministic detector와 source PDF bookmark 품질에 좌우된다. 011-013 실험의 tree/title/bookmarks-per-page 필터를 dataset 생성 단계에 더 명확히 반영해야 한다.
