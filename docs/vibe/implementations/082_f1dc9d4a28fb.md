## 변경 배경

- `pdfbooktree skill`에는 `install` 하나뿐이었고 제거 명령이 없었다. 한 번 설치하면 사용자가 이 패키지의 흔적을 걷어낼 방법이 없었다.
- `install`은 `.agents/skills/use-pdfbooktree`와 `.claude/skills/use-pdfbooktree`만 쓰고 `CLAUDE.md`나 `AGENTS.md`에는 아무것도 남기지 않았다. 그래서 skill이 설치돼 있어도 project의 instruction 파일만 읽는 도구는 이 패키지의 존재를 알 수 없었다.
- 갱신 범위는 이미 안전했다. 임시 project로 실측한 결과 `--force`는 우리 skill directory 안의 구버전 잔물만 지우고 사용자의 다른 skill(`.claude/skills/my-own-skill`, `.agents/skills/other-skill`)과 `CLAUDE.md`, `AGENTS.md`를 건드리지 않았다. 이 성질은 유지해야 한다.

## 결정 내용

- 등록과 제거를 대칭으로 만들었다. `install`이 두 instruction 파일에 짧은 pointer 블록을 남기고, `uninstall`이 그 블록과 두 skill target만 되돌린다.
- 사용자 파일을 다룰 때는 begin/end marker 안쪽만 읽고 쓴다. marker 바깥은 파싱하지도, 재정렬하지도 않는다. 사용자 규칙 문서를 우리가 소유한다고 가정하는 순간 되돌릴 수 없는 손상이 생긴다.
- 블록이 이미 있으면 그 구간만 교체한다. 그래서 여러 번 설치해도 블록이 쌓이지 않는다.
- 제거로 파일이 비면 파일까지 지우고, 다른 내용이 남아 있으면 파일을 남긴다. 우리가 만들지 않은 파일을 우리가 없앴다고 착각하지 않기 위해서다.
- 아무것도 설치돼 있지 않은 상태에서 `uninstall`은 실패가 아니라 "제거할 것이 없음"으로 보고한다. 정리 명령이 상태에 따라 실패하면 자동화에서 쓰기 어렵다.

## 작동 방식

- `install`은 agents target에 전체 지침 8개 파일을, Claude target에 adapter 1개를 쓰고, `AGENTS.md`와 `CLAUDE.md`에 marker로 감싼 pointer 블록을 넣는다. 파일이 없으면 블록만 담은 파일을 만든다.
- `uninstall`은 두 skill directory가 이 패키지가 소유한 것인지 확인한 뒤 제거하고, 두 instruction 파일에서 marker 구간만 잘라낸다. 제거한 항목을 결과로 보고한다.
- 두 함수 모두 공개 API로 내보내고, 저장소의 공개 symbol 문서화 계약에 따라 한국어와 영어 Python API reference에 함께 실었다.

## 대안과 제외한 선택지

- instruction 파일을 건드리지 않고 skill directory만 지우는 uninstall도 가능했지만, 그러면 "설치했는데 instruction에서는 안 보인다"는 기존 문제가 그대로 남는다. 등록과 제거를 함께 만들어야 대칭이 성립한다.
- marker 없이 특정 문구를 찾아 지우는 방식은 배제했다. 사용자가 우연히 같은 문구를 쓰면 사용자 문장을 지운다.
- 블록을 넣지 않고 uninstall에서만 지우도록 하는 방식도 배제했다. 생산자가 없는 제거 코드는 소비자 없는 config key와 같은 종류의 죽은 경로다.
- 파일이 없을 때 아무것도 하지 않는 안도 배제했다. skill을 설치한 project라면 instruction 파일이 생기는 편이 발견성에 낫고, 제거하면 다시 사라진다.

## 남은 리스크

- 사용자가 marker 자체를 손으로 수정하거나 한쪽 marker만 지우면 `uninstall`이 그 블록을 인식하지 못한다. 이때는 사용자 내용을 추측해 지우지 않고 남겨 두는 쪽을 택했다.
- 블록은 project 단위로만 등록된다. 전역 설정이나 사용자 홈의 skill 경로는 다루지 않는다.
- `install`이 이제 `AGENTS.md`와 `CLAUDE.md`를 만들 수 있다. 이 두 파일을 생성 자체로 원치 않는 project라면 예상 밖일 수 있으며, 그때는 `uninstall`로 되돌릴 수 있다.
