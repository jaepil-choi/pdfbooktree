## 변경 배경

- real-data showcase에서 Shreve PDF의 TOC page detection 결과가 `[2, 3, ..., 11]`로 나와 expected `[3, 4, ..., 11]` 대비 precision 0.9를 기록했다.
- page 2는 저작권/메타데이터 page였지만 line-final number `[1996, 1997]` 때문에 `window_mass` vote를 얻고, 기존 edge expansion이 이 page를 TOC segment 앞쪽에 붙였다.
- 사용자는 개별 page의 line-final number만 보지 말고 candidate segment 전체의 line-final number 흐름이 monotonically increasing한지를 보는 것이 핵심이라고 지적했다.

## 결정 내용

- `TocPageScore`에 `line_final_numbers`를 보존해 segment 확장 단계에서 page별 숫자열을 다시 볼 수 있게 했다.
- edge expansion을 `window_mass` 단일 vote 기반에서 segment-level number-flow 기반으로 바꿨다.
- 인접 page를 붙일 때 기존 segment 숫자열과 candidate page 숫자열을 이어 붙이고, boundary의 마지막/첫 숫자가 역행하면 확장하지 않는다.
- 확장 후 전체 sequence monotonicity가 기존 segment보다 크게 나빠지지 않을 때만 candidate page를 포함한다.
- bookmark-guided detector가 `TocPageScore`를 재구성할 때도 `line_final_numbers`를 유지하도록 맞췄다.

## 작동 방식

- `select_toc_segment()`는 strong segment 또는 window mass segment를 먼저 고른다.
- 이후 `expand_soft_edges()`가 좌우 인접 page를 검사한다.
- candidate page가 vote를 하나 이상 가지고 있고, candidate를 붙였을 때 segment 전체 line-final number 흐름이 유지되면 segment에 포함한다.
- Shreve page 2의 경우 candidate 숫자열 `[1996, 1997]` 뒤에 segment 시작 숫자열 `[1, ...]`이 오므로 boundary 역행으로 판단해 제외한다.
- 모든 page number는 기존 package 규칙에 따라 1-based로 유지한다.

## 대안과 제외한 선택지

- `1 <= n <= total_pdf_pages + 50` 같은 absolute number filter는 제외했다. printed page number와 PDF page count 관계는 책마다 다르고, appendix/index 등에서 쉽게 깨질 수 있다.
- `valid_final_number_count >= 5` 같은 최소 개수 조건도 제외했다. TOC 경계 page나 brief contents page는 숫자 후보가 적을 수 있어 recall을 해칠 수 있다.
- page-level monotonicity만 강화하는 방식도 제외했다. Shreve page 2의 `[1996, 1997]`처럼 page 내부에서는 완벽히 증가하지만 segment로 붙이면 역행하는 케이스를 잡지 못한다.

## 남은 리스크

- precision은 개선됐지만 runtime detector의 recall은 낮아졌다. John Hull의 뒤쪽 TOC page와 Luenberger의 brief contents page처럼 OCR line split이나 분리된 numeric column이 있는 경우를 더 잘 복원해야 한다.
- 다음 개선은 line-final regex 강화보다, standalone numeric lines와 title lines를 page/segment 수준에서 재조립하는 방향이 적절하다.
- segment-level monotonicity는 noise를 줄이는 데 유용하지만, OCR이 숫자 column을 심하게 뒤섞는 경우에는 LNDS 같은 더 robust한 sequence score가 필요하다.
