## 변경 배경

- PDF 전체에서 가장 빈도가 높은 font tier를 본문으로 취급하되, 본문 line은 BPE에서 삭제하지 않고 heading token 사이의 separator로 남겨야 했다.
- 080 실험은 직접 인접한 heading만 body line-spacing 기준으로 병합할 때 hierarchy pollution이 줄어든다는 점을 확인했다. 또한 015 실험은 상·하단 margin의 printed page number가 만드는 연속 offset run으로 page offset을 판별할 수 있음을 확인했다.
- Shreve에서는 OCR 본문이 BPE 병합 뒤 장문 node로 변하고 running header가 heading으로 유입됐다. Hull에서는 margin y 좌표만으로 제거하면 본문 첫 줄을 같이 잃는 회귀가 확인됐다.

## 결정 내용

- `TypographyConfig`에 BPE 병합, 장문 pollution, margin band, 연속 page 수열의 hyperparameter를 공개했다. CLI `process`는 핵심 BPE/margin 설정과 Markdown split 길이 정책을 받을 수 있다.
- 본문 및 더 작은 tier는 separator token으로 보존한다. BPE는 같은 page에서 separator 없이 직접 인접하고 body spacing보다 좁은 heading token만 병합한다.
- 30단어 초과 BPE node는 최종 bookmark level을 한 단계 낮춘다. 강등 뒤 특정 bookmark level의 pollution 비율이 30%를 초과하면 그 level 전체를 본문으로 제외한다.
- margin 전처리는 연속 printed-page offset run에 속하는 숫자를 가진 margin line만 제거한다. y 좌표가 같은 모든 line을 제거하지 않아 Hull의 본문 첫 줄 regression을 막는다. 기본 연속 run은 10페이지다.
- Markdown export는 모든 level cutoff의 파일 길이를 계산하고, coverage 제약을 충족하는 가장 얕은 level을 선택한다.

## 작동 방식

- `Processor`는 typography line을 추출한 뒤 margin artifact를 제거하고 font/height tier를 계산한다. 이후 BPE heading, stack hierarchy, bookmark plan 순으로 처리한다.
- margin 전처리는 1-based `pdf_page - printed_page` offset을 사용한다. offset이 설정된 길이 이상 연속되는 page run에 속할 때만 해당 숫자가 있는 상·하단 line을 제거하며, 정적으로 반복되는 margin text도 제거한다.
- Markdown split이 설정되면 bookmark plan을 level별로 렌더링하고, 각 파일의 word count·coverage·overflow를 manifest와 `MarkdownExportResult`로 반환한다.
- 기존 PDF outline을 유지하는 경로도 동일한 Markdown split export를 사용할 수 있다.

## 대안과 제외한 선택지

- 본문 font tier를 BPE 입력 전에 삭제하는 방식은 heading 사이 separator를 잃어 서로 떨어진 heading을 병합하므로 선택하지 않았다.
- font tier만 한 단계 낮추는 방식은 중간 tier가 없는 구간에서 실제 bookmark level이 바뀌지 않아 선택하지 않았다. 최종 hierarchy level을 직접 강등한다.
- margin y band 전체를 제거하는 방식은 Hull에서 본문 첫 줄과 footnote를 삭제했다. offset run과 숫자가 직접 일치하는 line만 제거한다.
- 책별 규칙이나 title lexical 예외는 사용하지 않았다.

## 남은 리스크

- 로마 숫자나 숫자가 없는 running header/footer는 정적 반복 text 이외에는 자동으로 제거하지 못할 수 있다.
- 10페이지보다 짧은 책은 기본 설정에서 page-number offset 제거가 보수적으로 비활성화될 수 있으며, 필요하면 `margin_min_consecutive_pages`를 낮춰야 한다.
- 수리통계학과 Algorithms to Live By에는 길이 제약을 완전히 충족하지 못하는 큰 Markdown 파일이 남아 있다. 이는 heading 품질과 별도로 split 정책에서 후속 검토가 필요하다.
