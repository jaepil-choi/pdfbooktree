## 변경 배경

- 실험 003은 TOC page range를 찾기 위해 printed page number sequence, TOC entry pattern, contiguous window mass, bookmark title anchor, target-page offset consistency를 함께 쓰는 deterministic ensemble이 세 샘플에서 검수 accepted range 대비 precision 1.0, recall 1.0을 달성함을 보였다.
- 직전 scaffold 커밋에서 bookmark 없이 동작하는 기본 detector와 bookmark 기준 신호를 쓰는 detector, metric 계산 모듈의 파일 경계를 분리했다.
- 이번 구현은 그 경계를 유지하면서 실험 003의 핵심 로직을 제품 코드로 옮겨 public interface가 실제 결과를 반환하게 만드는 단계다.

## 결정 내용

- `toc.features.PageFeature`에 `line_length_std`, `toc_entry_pattern_count`, `toc_entry_pattern_ratio`, `chapter_or_part_line_count`를 추가했다.
- `toc.segments`에는 page 단위 vote score와 연속 segment 선택 로직을 구현했다. 기본 detector는 bookmark 없는 입력만 쓰기 위해 printed page sequence, TOC entry pattern, window mass만 사용한다.
- `toc.detect.detect_toc_pages()`는 feature list를 받아 `TocDetectionResult`를 반환하는 기존 public contract를 유지하면서 `feature_vote_segment` 방식으로 동작하게 했다.
- `toc.detect_from_bookmarks.detect_toc_pages_from_bookmarks()`는 기존 bookmark title fuzzy anchor와 target-page offset consistency를 추가 vote로 사용한다.
- `metrics.toc_pages`에는 page set precision/recall, segment IoU, start/end boundary error를 계산하는 순수 함수를 구현했다.

## 작동 방식

- 기본 detector는 각 page feature에서 세 가지 독립 vote를 계산한다. line 끝 page number sequence가 충분히 강하면 `printed_page_sequence`, TOC item pattern이 많으면 `toc_entry_pattern`, 약한 연속 구간 mass가 있으면 `window_mass` vote가 붙는다.
- strong vote가 있는 연속 page segment를 먼저 고르고, 없으면 window mass와 boundary contrast가 큰 구간을 fallback으로 고른다. 근거가 없는 page만 들어온 경우에는 빈 결과를 반환한다.
- bookmark 기반 detector는 page line window와 bookmark title을 fuzzy matching하고, bookmark order density와 printed page number 대비 target page offset 일관성을 vote로 더한다.
- 모든 page number는 기존 package 규칙대로 1-based로 해석한다.

## 대안과 제외한 선택지

- 실험 003의 모든 weak labeler를 기본 detector에 넣는 방식은 제외했다. bookmark anchor와 target-page offset consistency는 bookmark가 있을 때만 의미가 있으므로 `detect_from_bookmarks`에만 둔다.
- LLM binomial search 실험 004는 기본 구현에 넣지 않았다. 실험 결과 Luenberger 샘플에서 recall이 낮았고, PRD도 LLM을 low-confidence fallback으로 제한한다.
- ML scorer는 아직 도입하지 않았다. 현재 단계에서는 deterministic feature/vote detector가 v0.1 구현 흐름을 빠르게 열어준다.

## 남은 리스크

- synthetic 단위 테스트는 통과하지만 실제 PDF 3종에 대한 showcase 또는 integration 검증은 아직 별도 단계가 필요하다.
- threshold는 실험 003의 소수 샘플에서 출발한 값이라 더 다양한 textbook에서 보정해야 한다.
