## 작동 방식

- `pyproject.toml`의 `readme = "README.md"` 설정에 따라 한국어 README가 PyPI의
  장문 설명으로 들어간다.
- `project.description`은 PyPI 검색 결과와 프로젝트 머리말에 표시되는 짧은
  설명으로 들어간다.
- README는 기본 `process` 흐름을 먼저 보여 주고, 검토가 필요한 경우에만
  `infer → inspect → apply` 흐름을 소개한다.
- 출력 예시는 실제 실행 구조인 책별 디렉터리와 실행 ID 디렉터리의 두 단계를
  표시한다.
