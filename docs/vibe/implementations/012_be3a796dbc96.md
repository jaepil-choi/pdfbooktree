## 변경 배경

- PRD v0.3은 TOC page detector를 fixed weight score가 아니라 수동 검수 label 기반 ML scorer로 학습하도록 요구한다.
- 기존 `src/`에는 bookmark 없는 기본 detector와 bookmark-guided pseudo label 생성 흐름은 있었지만, `manual_reviewed` label만 ground truth로 쓰는 trainer, GroupKFold 평가, model artifact 저장/로드, `train-toc-detector` CLI가 없었다.
- 300study bookmark-guided label은 검수 전 ground truth로 쓰면 안 된다는 판단이 이미 내려졌으므로, pseudo label을 학습에서 거부하는 정책을 코드에 명시할 필요가 있었다.

## 결정 내용

- `pdfbooktree.toc.training` 모듈을 새로 추가해 학습 흐름을 기존 heuristic detector와 분리했다.
- public API로 `TocDetectorTrainer`, `TocDetectorModel`, `TocDetectorTrainingResult`를 export하고, CLI에 `pdfbooktree train-toc-detector` 명령을 추가했다.
- label 정책은 `review_status == "manual_reviewed"`만 허용하는 방식으로 고정했다. `unreviewed` pseudo label은 rejected label로 기록하고, 유효 label이 없으면 학습을 중단한다.
- 기본 feature set은 PRD의 objective feature만 사용한다. 기존 `toc_entry_pattern_*`, previous-page feature, bookmark-guided feature는 기본 학습 feature에서 제외했다.
- 기본 target은 page-level soft label regression으로 두고, segment-level IoU target 함수는 후속 확장을 위해 순수 함수로 제공한다.

## 작동 방식

- `TocDetectorTrainer.run()`은 label JSON을 읽고 manual-reviewed label만 남긴 뒤 PDF 존재 여부, 1-based page range, `max_text_pages` 범위를 검증한다.
- 각 PDF 앞부분에서 page text와 objective feature를 추출하고, TOC range 내부는 1.0, 양쪽 1 page는 0.5, 양쪽 2 page는 0.2, 나머지는 0.0으로 soft target을 만든다.
- 평가는 PDF path를 group으로 삼는 `GroupKFold`만 사용한다. fold별 예측 score는 연속 page segment로 변환한 뒤 segment IoU와 start/end boundary error로 채점한다.
- 최종 모델은 전체 accepted label row로 다시 학습하고, `joblib` artifact에 model, feature names, label policy, training summary, package version을 함께 저장한다.
- `TocDetectorModel.load()`는 저장 artifact를 로드하고, `predict()`는 page feature list에서 `TocDetectionResult`를 반환한다. 기존 `Processor` 런타임 detector는 아직 교체하지 않았다.

## 대안과 제외한 선택지

- 기존 `feature_vote_segment` detector를 ML detector로 즉시 교체하지 않았다. 학습 artifact를 만든 뒤 별도 검증 없이 런타임 처리 경로를 바꾸면 기존 scaffold 동작의 의미가 바뀌기 때문이다.
- bookmark-guided pseudo label을 weak-label imitation 학습 모드로 허용하지 않았다. 이번 구현의 목적은 PRD compliant ground-truth 학습 경로를 만드는 것이므로 기본 경로에서는 수동 검수 label만 허용한다.
- LightGBM 기반 실험 코드를 `src/`로 승격하지 않았다. PRD 후보 모델인 decision tree, random forest, histogram gradient boosting regressor만 기본 옵션으로 제공한다.

## 남은 리스크

- 실제 300study pseudo label은 대부분 `unreviewed`라 현재 trainer에 넣으면 학습이 거부된다. 수동 검수 label 파일을 별도로 만들어야 실제 train/test가 가능하다.
- `TocDetectorModel.predict()`는 저장 모델 적용 API만 제공하며, `Processor`에서 자동으로 사용되지는 않는다.
- segment 선택은 page score threshold와 score mass 기반의 단순 방식이다. 실제 manual-reviewed corpus가 쌓이면 threshold, 후보 segment 생성, segment-level IoU regression 전환을 다시 검증해야 한다.
